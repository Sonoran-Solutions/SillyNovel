## Using the Scene controls

Explicitly attach an independent project to an individual conversation. The saved background, manual actor UUIDs, presence, slots, outfits and locks remain global across messages. Select a manual actor in Scene, navigate to a stable message, enter a temporary expression label and import a static PNG through **Temporary expression PNG**. Import registers a choice without applying it. The **Expression to apply · selected source only** chooser is a pending choice, separate from the current-expression status; imported choices remain selected deliberately. Choose **Apply expression** to apply it to this message, or **Clear expression** to return to the global base outfit. Import multiple PNGs for separate choices such as Happy and Stern.

The import explicitly binds that PNG to the selected actor UUID and its exact current outfit reference/revision. Names and filenames supply display labels only; neither native speaker/card mapping nor artwork compatibility is guessed. Duplicate actor names retain UUID disambiguation. Choices for other actors/outfits are excluded from the attached expression selector and refused by the model. An outfit change discards that actor's incompatible temporary assets/decisions, including a change back to a previously used outfit. Global locks remain deliberate global choices.

The selected-message line shows the native position/author for orientation, manual actor, current expression, temporary scope and invalidation/refusal feedback. Position is display data, never identity. Reading and the native composer remain available on processing failure. Global layout remains visible when source authority is unresolved. ## Source authority and projection

`project-scene.mjs` continues to run all durable arrangement commands against its existing synthetic `project-global` source. Its serialization reads only that original reducer view and persistent library. It composes a projection from `project-expressions.mjs` for the existing single stage renderer; expression commands never enter the global reducer or its revision counters.

The memory journal reuses `fingerprintHistory` without a second fingerprinting algorithm. Reader WeakMap host-object keys, per-source revisions, selected swipe, verified active reader owner/session epoch and ordered `sn-source-v1` prefix records establish correspondence within this activation only. Hashes are change evidence, never ownership credentials or durable native identity. The reader adds `selectionRevision`: activation, Previous/Next and Jump to Latest increment it; ordinary canonical reconciliation does not. The reader also exposes `sourceOrderRevision` for changes to ordered source keys, count or availability. The shared evidence stamp includes that revision: unchanged-object reorders trigger reconciliation and immediately hide overrides while new prefixes are checked. Neither revision changes on text scrolling or unchanged refreshes; `viewRevision` retains its broader display meaning.

An expression decision contains the exact verified source record, explicit actor UUID, and immutable temporary asset ID/revision; the asset pins the actor's full outfit reference. Navigation displays only decisions at the exact selected source. Unchanged revisits restore them, including separate equal-text messages. Appending while pinned preserves existing prefixes. Ambiguous/unavailable history or exceeded source-validation limits clears temporary authority/assets and retains the global layout. No reconstruction from text, hashes, DOM positions, native avatar filenames or numeric indices occurs.

The first differing ordered source record permanently invalidates decisions from that prior position onward. This matches the reducer's dependent-suffix rule for edit, same-length replacement, author/swipe change, insertion/deletion, host-object replacement, reorder and continuation/stream growth. A manual apply/clear at an older source also invalidates strictly later decisions; same-source choices for other actors remain independent. Refused operations do not invalidate decisions. The small separate expression journal implements these rules because replaying global arrangement commands against native history would change project-global semantics; the shared reducer and its contracts are unchanged.

A generation actively streaming at this source, or ended without resolved completion provenance, refuses expression authority. A new unbound generation also refuses at the head. Older stable sources remain usable. `GENERATION_ENDED` never proves successful completion. An explicitly stopped partial source can receive a deliberate manual expression at its current verified revision; further content/swipe changes invalidate it.

## Asynchronous artwork and cleanup

Before file read/decode, capture attachment lifetime, project-global reducer revision, owner/session/source signature, selection/history revisions and exact source record. Fresh canonical evidence is sampled before creating a URL and again after actual image decoding. Selection away/back, source/history/swipe changes, any global edit, actor chooser changes, outfit changes, chat switch, project replacement, detach, disable and disposal refuse stale results. Cancellation alone is not an authority check. UI actor selection is checked separately from the captured explicit actor UUID.

Only MIME-matching static PNG with exact signature/chunk boundaries/IHDR/IEND, no APNG animation, bounded dimensions and successful browser decode is accepted. Ceilings: 5 MiB per image; 4096px per edge / 16M pixels per image; 32 images / 32 MiB encoded / 32M decoded pixels per attachment; one pending decode; 400 source/actor decisions. The unchanged incremental prefix cache retains its 8 MiB / 5 second ceilings. Limits refuse with instructions to clear choices or detach/reopen. No new dependency, network image fetch, generation, persistent expression registration or schema change.

URLs release on failure, stale completion, source invalidation of pending work, incompatible outfit replacement and disposal. Assets whose last referencing decision is invalidated by changed source history are released; other compatible reusable choices remain bounded until attachment disposal. A missing/failed expression image is marked unavailable, its URL released and the existing base outfit rendered; no other expression is selected automatically. Clear removes the decision while retaining reusable compatible artwork. Detach/replacement, epoch/chat changes including A→B→A, disable/disposal and reload discard all temporary state.
